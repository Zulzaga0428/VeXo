## HeyGen Video Agent — Архитектурын бүрэн шинжилгээ

### 1. Үндсэн архитектур: Multi-agent + Resource-based system

HeyGen `agent_version: 2`, `agent_mode: "super_agent"` гэсэн **супер-агент orchestrator** ашигладаг. Энэ нь нэг том агентаар бүгдийг хийхгүй, харин дэд агентууд (жишээ нь `storyboard_builder`) болон **dynamic capability loading** (`load_capability`) -аар tool-уудаа динамикаар ачаалж ажилладаг.

**Гол зарчим:** Аватар, хоолой, загвар (style) бүгд **тус тусдаа resource болж үүсгэгдээд `resource_id`-аар холбогддог** (decoupled). Шууд биш — pointer/reference системээр. Энэ нь чиний асуудлын гол шалтгаан байж магадгүй.

### 2. Tool-уудын яг дараалал (бодит лог)

```
load_capability          → чадавхиа динамикаар ачаалах
create_blueprint         → төлөвлөгөө үүсгэх (voice/avatar = null-аар)
generate_narrator_image  → аватарын ЗУРАГ үүсгэх
generate_narrator_from_image → зургийг ЯРЬДАГ (lip-sync) narrator болгох ← КРИТИК
generate_voice_from_description → хоолойг ТУСАД нь үүсгэх
update_blueprint         → resource_id-уудыг blueprint-д холбох (patch)
get_user_response        → хэрэглэгчээс баталгаа авах
apply_blueprint          → narrator+voice+blueprint-ийг storyboard-д холбох
submit_video_generation_request → эцсийн видео рендер
```

### 3. ⚠️ ЧИНИЙ LIP-SYNC АСУУДЛЫН ГОЛ ШАЛТГААН

Чиний "хоолой ажиллаад зураг ярихгүй" асуудлын учир энд байна:

HeyGen зургийг **шууд хоолойтой нийлүүлдэггүй**. Хооронд нь **`generate_narrator_from_image`** гэсэн тусдаа, заавал шаардлагатай алхам байдаг — энэ нь статик зургийг "ярьж чаддаг narrator" (animatable talking head) болгож хувиргадаг. Хэрэв таны Kling/Veo pipeline зургийг шууд TTS аудиотой холбох гэж оролдвол → хоолой гарна, зураг ярихгүй. **Зургийг эхлээд "talking-capable narrator resource" болгох алхам дутуу байна.**

### 4. Blueprint бүтэц (хамгийн чухал schema)

```json
{
  "include_voice": true, "include_narrator": true,
  "voice": null, "avatar": null,
  "voice_resource_id": "voice_5j2pif",      // тусдаа resource
  "narrator_resource_id": "narrator_pnsjzu", // тусдаа resource
  "style_resource_id": "style_tvjkzn",
  "language": "mn-MN", "orientation": "landscape",
  "scene_count": 2, "total_duration": 6, "captions": true,
  "scenes": [
    { "title": "...", "scene_type": "a_roll",
      "start_time": 0, "end_time": 3,
      "vo_script": "...", "visual": "...", "is_cinematic": false }
  ]
}
```

**Чухал:** Scene бүр `start_time`/`end_time` гэсэн **timecode**-той ба `vo_script` (хоолойны текст) тэр цаг хугацаатай уялддаг. `scene_type: a_roll` = аватар ярьдаг scene, b_roll = дүрслэх scene.

### 5. Замбараагүй болохоос сэргийлэх критик дүрмүүд (HeyGen өөрийн зааврууд)

- **Sequential order: Resources → Scenes → Timeline → Submit.** Дараагийн алхам руу орохоосоо өмнө generation дуусахыг хүлээх.
- **`apply_blueprint` болон `submit_video_generation_request` -ийг ГАНЦААРАА** дуудах, бусад tool-той batch хийхгүй.
- **Progressive patching:** create_blueprint-ийг voice/avatar = null-аар үүсгээд, аватар ба хоолойг **зэрэгцээ (parallel)** үүсгэж, бэлэн болмогц `update_blueprint`-аар patch хийнэ.
- **A-roll бүх scene нэг л narrator-ийн дүртэй** байх ёстой (нэг видеонд олон outfit боломжгүй).

### 6. State management

Background tasks (`bg_task_xxx`) async ажилладаг (visual generation blocking биш). Агент бүх төлвөө **S3 snapshot** (`v2a_snapshot_url`) болгож хадгалдаг — алдаа гарсан үед сэргээх боломжтой.

---

### 🔧 Replit агентдаа хийх 3 гол засвар

Чиний Kling/Veo агент яг энэ дарааллыг дагаж засвал хоолой+зураг синхрон болно:

**(1) Зургийг шууд voice-той бүү нийлүүл.** Эхлээд зургийг lip-sync чадвартай talking-head болгох тусдаа алхам (image-to-video / talking avatar) нэм. HeyGen-ийн `generate_narrator_from_image`-тэй ижил.

**(2) Resource-based decoupling нэвтрүүл.** voice, avatar-ыг тусдаа үүсгээд ID-аар холбо. Хооронд нь blueprint/manifest объект тавь (voice_resource_id, narrator_resource_id).

**(3) Timecode-based scene уялдуулалт хий.** vo_script бүрийг scene-ийн start/end_time-той тааруул — ингэснээр аудио-ийн урт ба видеоны урт зөрөхгүй, lip-sync ажиллана.
